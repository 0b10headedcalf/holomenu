# HoloMenu — See What You'll Actually Get

**Don't imagine your order. Experience it before it arrives.**

Meta Global AI Developer Hackathon · Indie track · Due Nov 4, 9PM ET

Every day, millions of people order food from a few lines of text, polished marketing photos, and reviews. None of these show what will actually arrive. HoloMenu turns **real customer photos** into interactive 3D previews you can rotate, place on your table, compare at true scale, and ask questions about — with a **TruthScore** that says when the evidence is thin.

## What makes it not "another AR menu"

1. **TruthScore + evidence strip** — every 3D model sits above the actual customer photos it came from, scored on portion / presentation / color agreement. Low evidence is labeled low (try the sushi).
2. **0-second illusion** — demo dishes are pre-reconstructed and cached, so the model appears instantly; live single-photo jobs run on Modal behind the same API.
3. **Conversational spatial Q&A** — "Enough for two?" "How big, really?" answered by Muse Spark grounded in measured size, weight, ingredients, and uncertainty notes.

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000 — works with NO API keys
```

Routes: `/` scan + catalogue · `/dish/[id]` 3D + TruthScore + chat · `/compare?a=ramen&b=pizza` · `/glasses` Ray-Ban Display web-app view (voice: say "next"/"back") · APIs under `/api/*`.

Works offline by design: without keys, menu scan / chat / reconstruction return deterministic local fallbacks from cached models. Demo never dies.

## Go live (optional, in order)

```bash
cp .env.example .env.local   # fill META_API_KEY / META_API_BASE_URL / META_MODEL from the hackathon portal
pip install modal && modal deploy modal/reconstruct.py   # copy endpoint URL into MODAL_ENDPOINT_URL
npm run build && npm start
```

Regenerate placeholder 3D models: `python3 -m venv /tmp/venv && /tmp/venv/bin/pip install trimesh numpy scipy && /tmp/venv/bin/python scripts/generate_models.py`

## Architecture

```
Phone browser / Ray-Ban Display (same URL)
  └─ Next.js + <model-viewer> (rotate / zoom / AR place-on-table)
       ├─ POST /api/menu-scan    Muse Spark VLM: menu photo → dish list
       ├─ POST /api/chat         Muse Spark Q&A grounded in dish evidence
       ├─ POST /api/reconstruct  → Modal GPU: SAM 3.1 segment → TripoSR → .glb (cached)
       └─ lib/scoring.ts         TruthScore from cross-photo agreement
```

Key files: `src/lib/dishes.ts` (data + evidence), `src/lib/meta.ts` (only place that talks to Meta), `src/lib/scoring.ts`, `modal/reconstruct.py`, `DEMO.md` (60s filming script + submission checklist).

## What's real vs cached — say this to judges

- **Real:** menu-scan parsing, chat reasoning, TruthScore computation, true-scale compare, glasses voice nav — all live code paths (Meta API when keys are set, local fallback otherwise).
- **Cached:** the 6 demo `.glb` files in `public/models/` are stylized placeholders generated by `scripts/generate_models.py`. The Modal pipeline (`modal/reconstruct.py`) is deploy-ready with SAM 3.1 + TripoSR marked where weights plug in. Don't claim live multi-photo NeRF reconstruction — claim single-photo reconstruction + cross-photo evidence scoring. That's the honest, buildable version.
